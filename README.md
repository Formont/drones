# Drones

Unity project for a city drone-piloting campaign.

## Open the project

- Unity version: `6000.6.7f1`
- Open this folder in Unity Hub.
- Start from `Assets/Scenes/MainMenu.unity`; the campaign map and missions are in `Assets/Scenes/CampaignMap.unity`, `Assets/Scenes/lvl 1.unity`, and `Assets/Scenes/lvl2.unity`.

## Controls

- `WASD` — steer
- `Space` / `Ctrl` — ascend / descend
- Mouse — look
- `E` — toggle motors
- `K` — release a delivery package
- `Esc` — pause

## Third-party assets

Licensed source files for the POLYGON city pack, FREE Cartoon Car Pack, drone pack, and Aegis77 cardboard box pack are not mirrored here. Install your licensed copies into their original `Assets` folders before opening the scenes. Their Unity `.meta` files are retained so the scene references keep their GUIDs.
